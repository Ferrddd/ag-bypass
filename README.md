# Antigravity Windows Bypass (ag-custom for Windows)

Автономное решение для стабильной работы с **Google Antigravity** (`agy.exe`) в РФ и других заблокированных регионах без использования VPN-клиентов, прокси-демонов и стороннего ПО.

---

## ⚡ Особенности реализации под Windows

- **0 внешних зависимостей:** Доступны сразу два режима работы:
  1. **Python 3:** на чистой стандартной библиотеке (`socket`, `ssl`, `struct`, `winreg`, `ctypes`) — никаких `pip install` не требуется.
  2. **Standalone PowerShell (`ag.ps1`):** полностью автономный скрипт на .NET (`System.Net.Sockets`, `SslStream`), работающий в чистой Windows **вообще без Python**.
- **Без сторонних прокси-демонов в памяти:** Никаких фоновых процессов, потребляющих RAM и процессор. Трафик идёт к зарубежным узлам напрямую через SNI-проксирование.
- **Точечная Split-DNS маршрутизация через Hosts:** Перенаправляется исключительно рабочий домен `daily-cloudcode-pa.googleapis.com` в `C:\Windows\System32\drivers\etc\hosts`. Весь остальной интернет, игры, браузер и мессенджеры работают напрямую на максимальной скорости вашего провайдера.
- **Авто-патчинг `agy.exe`:** Автоматически находит клиент и безопасно заменяет проверку доступности региона (`ineligible` $\to$ `inexigible`, ровно 10 байт в 10 байт) с сохранением резервной копии `agy.exe.bak`.
- **Фоновый самохилинг через Планировщик Windows (Task Scheduler):** Задача `AntigravityBypass` раз в 15 минут в скрытом режиме проверяет отклик текущего сервера и при необходимости на лету переключает на живой резервный узел.

## 🚀 Быстрый старт

### Способ 1. Автоматическая установка (Рекомендуется)

1. Скачайте или клонируйте репозиторий в удобную папку (например, `C:\Tools\ag-custom-windows`):
   ```powershell
   git clone <repo-url> C:\Tools\ag-custom-windows
   cd C:\Tools\ag-custom-windows
   ```
2. Запустите файл `install.bat` двойным кликом (или правой кнопкой мыши $\to$ **Запуск от имени администратора**).
   * Скрипт проверит наличие Python.
   * Добавит папку в переменную `PATH` пользователя (команда `ag` станет доступна из любого места системы).
   * Зарегистрирует фоновую задачу проверки узлов в Планировщике Windows.
3. Откройте **Терминал Windows / PowerShell от имени Администратора** и включите обход:
   ```cmd
   ag on
   ```
   *(Если вы используете чистый PowerShell без Python, запускайте `.\ag.ps1 on`)*.

---

### Способ 2. Автономный запуск через PowerShell (без установки Python)

Если на вашем компьютере не установлен Python:

1. Откройте PowerShell от имени Администратора в папке с проектом:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\ag.ps1 on
   ```
2. Всё готово! Antigravity будет работать штатно.

## 🛠️ Справка по командам

| Команда | Описание |
|---|---|
| `ag on` *(или `.\ag.ps1 on`)* | **Включить обход:** патчит `agy.exe`, запрашивает адреса у SmartDNS, тестирует пинг, выбирает лучший IP и прописывает в `hosts` |
| `ag status` *(или `.\ag.ps1 status`)* | **Статус системы:** состояние патча бинарника, статус переменной `CLOUD_CODE_URL`, текущий активный узел, пинг и статус планировщика |
| `ag nodes` *(или `.\ag.ps1 nodes`)* | **Тест всех узлов:** параллельный опрос всех доступных прокси-нод и вывод таблицы пингов |
| `ag check` *(или `.\ag.ps1 check`)* | **Ручная проверка:** проверяет текущий узел и автоматически переключает на резервный, если текущий недоступен |
| `ag off` *(или `.\ag.ps1 off`)* | **Отключить обход:** очищает блок в файле `hosts`, сбрасывает DNS-кэш (`ipconfig /flushdns`) и удаляет переменную окружения |
| `ag unpatch` *(или `.\ag.ps1 unpatch`)* | **Откат клиента:** восстанавливает оригинальный бинарник `agy.exe` из бэкапа `.bak` |

## 🔍 Как это устроено под капотом

1. **RFC 1035 UDP DNS-резолвер (`core/resolver.py` / `Get-SmartDnsNodes`):**  
   Формирует бинарный DNS-запрос и парсит ответ напрямую через UDP порт 53 к SmartDNS (`dns.geohide.ru` / `45.155.204.190`), извлекая динамический пул актуальных A-записей.
2. **TLS SNI Checker (`core/checker.py` / `Test-TlsNode`):**  
   Открывает сокет по порту 443 к каждому IP с указанием TLS SNI `daily-cloudcode-pa.googleapis.com`, замеряет точное RTT и отправляет проверочный `HEAD / HTTP/1.1`, отсекая недоступные или заблокированные адреса.
3. **Безопасный менеджер `hosts` (`core/hosts.py` / `Set-HostsIp`):**  
   Вносит изменения в `C:\Windows\System32\drivers\etc\hosts` строго между маркерами `# BEGIN AG_BYPASS` и `# END AG_BYPASS`. Перед записью снимает атрибут Read-Only (если установлен антивирусом), создаёт бэкап `hosts.ag_bak` и вызывает системный сброс DNS через `ipconfig /flushdns`.
4. **Binary Patcher (`core/patcher.py` / `Patch-Binary`):**  
   Ищет в бинарнике клиента `ineligible` и заменяет на `inexigible`. Это обходит клиентский запрет на работу в неподдерживаемом регионе.
5. **Планировщик задач (`core/scheduler.py`):**  
   Создает задачу `AntigravityBypass` в Windows Task Scheduler. При вызове через Python используется `pythonw.exe`, благодаря чему фоновая проверка раз в 15 минут выполняется абсолютно незаметно (без мигания черных окон консоли).

## ⚙️ Настройка (`config.json`)

```json
{
  "smart_dns": {
    "host": "dns.geohide.ru",
    "fallback_ip": "45.155.204.190",
    "port": 53,
    "timeout_seconds": 3.0
  },
  "domains": [
    "daily-cloudcode-pa.googleapis.com"
  ],
  "binary_path": "auto",
  "healthcheck": {
    "interval_minutes": 15,
    "connect_timeout_seconds": 2.5,
    "probe_port": 443,
    "retries": 3,
    "retry_delay_seconds": 1.0
  }
}
```

* `binary_path`: `"auto"` (автопоиск в `%USERPROFILE%\.local\bin`, `%LOCALAPPDATA%`, `PATH`) или явный путь (например, `"C:\\Users\\User\\.local\\bin\\agy.exe"`).
* `healthcheck.interval_minutes`: интервал фоновой проверки в минутах (по умолчанию 15).

## ❓ Частые вопросы и диагностика

### «Ошибка: Для команды 'on' требуются права Администратора»
Файл `hosts` и системные переменные защищены ОС Windows. Запускайте PowerShell или Терминал через **Правый клик $\to$ Запуск от имени администратора**.

### «Антивирус блокирует изменение файла hosts»
Некоторые антивирусы (Kaspersky, Dr.Web, Windows Defender) по умолчанию защищают файл `hosts` от записи. Добавьте файл `hosts` или папку утилиты в доверенные исключения.

### «Бинарник agy.exe запущен и не может быть перезаписан»
В Windows запущенный исполняемый файл блокируется ядром ОС на запись. Закройте приложение или завершите процесс `agy.exe` в Диспетчере задач перед выполнением `ag on` или `ag unpatch`.
