# Antigravity Linux Bypass (ag-custom)

Легковесное, полностью автономное решение для работы с **Google Antigravity** в заблокированных регионах без сторонних прокси-демонов, внешних зависимостей и привязок к HWID.

---

## ⚡ Особенности

- **0 внешних зависимостей:** Работает «из коробки» на стандартной библиотеке Python 3 (`socket`, `ssl`, `struct`, `pathlib` и т.д.). Никаких `pip install`, `virtualenv` или компиляторов.
- **Без локальных демонов:** Не держит в памяти постоянно работающие proxy-серверы. Система обращается к узлам обхода напрямую через быстрое SNI-проксирование.
- **Точечная маршрутизация (Split-DNS):** Через `/etc/hosts` перенаправляется исключительно рабочий домен Antigravity (`daily-cloudcode-pa.googleapis.com`). Весь остальной интернет-трафик системы идёт напрямую.
- **Автоматический выбор лучшего узла:** Резолвит актуальные IP через SmartDNS (`dns.geohide.ru`), тестирует TLS 443 хэндшейк и ранжирует узлы по минимальному пингу.
- **Авто-патчинг клиента:** Находит бинарник `agy` и безопасно модифицирует проверку доступности региона (`ineligible` $\to$ `inexigible`, 10 байт в 10 байт) с сохранением `.bak` бэкапа.
- **Фоновый мониторинг (Systemd Timer):** Опциональный таймер проверяет доступность узла раз в 15 минут и при падении автоматически переключается на живой резервный сервер.

## 🚀 Быстрый старт

### 1. Установка
```bash
git clone <repo-url> ag-custom
cd ag-custom

# Базовая установка (создаёт команду ag в ~/.local/bin/ag):
./install.sh

# Или системная установка с таймером авто-восстановления:
sudo ./install.sh
```

### 2. Включение обхода
```bash
sudo ag on
```
Команда:
1. Автоматически найдёт и пропатчит клиент `agy` (создав резервную копию `agy.bak`).
2. Запросит актуальные IP у SmartDNS.
3. Проверит скорость каждого узла через TLS-рукопожатие на порту 443.
4. Добавит лучший узел в `/etc/hosts` и сбросит системный DNS-кэш (`resolvectl flush-caches`).

### 3. Проверка статуса
```bash
ag status
```
Выведет:
- Статус патча бинарника `agy`
- Текущие записи в `/etc/hosts`
- Проверку доступности активного прокси-узла и его задержку в миллисекундах
- Состояние службы фонового мониторинга

### 4. Отключение обхода
```bash
sudo ag off
```
Бесследно удаляет блок записей из `/etc/hosts` и сбрасывает кэш DNS.

## ⚙️ Конфигурация (`config.json`)

Вся настройка осуществляется через простой JSON-файл:

```json
{
  "smart_dns": {
    "host": "dns.geohide.ru",
    "fallback_ip": "45.155.204.190",
    "port": 53,
    "timeout_seconds": 3.0
  },
  "domains": [
    "daily-cloudcode-pa.googleapis.com"
  ],
  "binary_path": "auto",
  "healthcheck": {
    "interval_minutes": 15,
    "connect_timeout_seconds": 2.5,
    "probe_port": 443
  }
}
```

- **`smart_dns.host`**: Имя хоста SmartDNS (резолвится стандартным DNS-клиентом).
- **`smart_dns.fallback_ip`**: Резервный IP-адрес DNS на случай проблем с резолвом имени.
- **`domains`**: Список доменов, которые направляются на прокси-узлы.
- **`binary_path`**: `"auto"` для автопоиска в `~/.local/bin/agy`, `PATH` или `/opt/...`, либо прямой путь к файлу.
- **`healthcheck`**: Таймауты и параметры проверки здоровья узла.

## 🛠️ Справка по командам

| Команда | Описание |
|---|---|
| `sudo ag on` | Включить обход: пропатчить клиент, найти лучший IP и прописать в `/etc/hosts` |
| `sudo ag off` | Отключить обход: удалить записи из `/etc/hosts` и сбросить DNS-кэш |
| `ag status` | Показать статус бинарника, текущий узел и его задержку (не требует `sudo`) |
| `sudo ag check` | Проверить доступность узла. При падении интерактивно предложит новый сервер |
| `sudo ag check --non-interactive` | Автоматически переключить на живой узел без подтверждения (используется таймером) |
| `sudo ag unpatch` | Восстановить оригинальный бинарник `agy` из бэкапа `.bak` |

## 🔍 Как это работает изнутри

1. **RFC 1035 UDP DNS-клиент (`core/resolver.py`):**  
   Формирует бинарный DNS-запрос и парсит ответы без внешних библиотек (`dnspython`), извлекая A-записи целевого домена из SmartDNS.
2. **TLS SNI Checker (`core/checker.py`):**  
   Открывает SSL-сокет к каждому кандидату с SNI `daily-cloudcode-pa.googleapis.com`, замеряет round-trip время и отправляет тестовый `HEAD /` запрос для подтверждения ответа Google Frontend.
3. **Атомарный менеджер `/etc/hosts` (`core/hosts.py`):**  
   Изолирует записи между тегами `# BEGIN AG_BYPASS` и `# END AG_BYPASS`. Запись производится через временный файл с последующим `os.replace`, исключая повреждение системных файлов при сбоях. После записи сбрасывает кэш `systemd-resolved` / `resolvectl`.
4. **Бинарный патчер (`core/patcher.py`):**  
   Заменяет строку `ineligible` (10 байт) на `inexigible` (10 байт) в Go-бинарнике. Это предотвращает обработку отказа региона на стороне клиента и позволяет Antigravity штатно выполнять генерации.
